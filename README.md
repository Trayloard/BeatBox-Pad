# BeatBox Pad

Vocal drum machine controller for the browser. Beatbox into the microphone to trigger synthesized drum pads, record patterns, and use the AI ad-lib agent.

## Included

- React/Vite BeatBox Pad web app
- Web Audio API drum synthesis and FFT onset detection
- 16-pad sequencer
- AI ad-lib agent API route
- Text-to-speech widget
- PWA manifest and service worker
